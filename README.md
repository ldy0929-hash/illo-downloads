# 일로 · ILLO

Windows에서 견적, 캡처, PDF와 문서 작업을 한곳에서 처리하는 개인 업무 도구입니다.

## 다운로드

[최신 설치 파일](https://github.com/ldy0929-hash/illo-downloads/releases/latest)

Windows 10/11 64비트용입니다. 설치 파일 하나에 일로 작업실, 캡처, PDF, 문서 작업실이 포함됩니다.

## 0.7 주요 기능

- 무료 로컬 한글·영문 OCR → 품목 검토 → 견적 가져오기
- PDF 자르기, 글자·서명·도장, 페이지 번호, 원문 제거 방식의 가리기
- 이전 견적과 수정본의 품목·수량·단가·금액 비교
- 파일 끌어 놓기와 다음 작업 안내, Office → PDF, Excel 표 PDF
- 견적서·거래명세서·회사 서류를 PDF 또는 ZIP으로 묶기
- 설정에서 업데이트 확인·다운로드·설치

OCR 결과는 원본과 대조하세요. Word·PowerPoint와 Excel 원본 서식 변환에는 해당 Microsoft Office 앱이 필요합니다. Excel의 **표만 PDF**는 Office 없이 동작하며 차트·그림·원본 서식을 제외하고 저장된 계산값을 사용합니다. PDF 편집 결과는 이미지 PDF입니다.

저장 자료는 설치 폴더와 별도인 `%APPDATA%\Moa`에 유지됩니다. 배포 파일에 사용자의 견적·API 키·캡처 자료는 포함하지 않습니다.

처음 실행할 때 Windows에서 알 수 없는 게시자로 표시될 수 있습니다. 이 배포본은 유료 코드 서명 인증서를 사용하지 않습니다.
